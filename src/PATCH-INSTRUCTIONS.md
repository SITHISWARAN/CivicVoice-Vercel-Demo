# CivicVoice viewport-fit patch

Replace only these two existing files:
- `src/App.jsx`
- `src/styles.css`

This patch aligns the Ready to start status pill on the right side of “Tell us what needs attention”, keeps the eight language options in one horizontal row (with horizontal scrolling on narrow screens), and adjusts the conversation panel so the chat area can flex while the mic/composer remains visible. All speech, language, API, and backend logic is unchanged.
